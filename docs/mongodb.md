## Документ і колекція

За замовчуванням база — `cats_db`, колекція — `cats`.
Під час запуску CLI створюється унікальний індекс `name`.
Ім'я чутливе до регістру; пробіли з країв видаляються.

```javascript
{
    _id: ObjectId("507f1f77bcf86cd799439011"),
    name: "barsik",
    age: 3,
    features: ["ходить в капці", "дає себе гладити", "рудий"]
}
```

`age` — невід'ємне ціле число до `2**63 - 1`; логічні значення не приймаються.
`features` — список непорожніх рядків; повтори прибираються, порожній список дозволено.
Ці правила перевіряє Python-застосунок. Серверний validator `$jsonSchema` не налаштований;
унікальність імен забезпечує індекс БД, але прямі записи можуть обійти перевірку полів.
У `create_cat` відсутній `_id` заповнює драйвер PyMongo перед `insert_one`
([документація драйвера](https://www.mongodb.com/docs/languages/python/pymongo-driver/current/crud/insert/)).
JSON-вивід меню використовує BSON Extended JSON.

## Запуск і операції

```bash
uv run --locked python main.py --seed
uv run --locked python main.py
```

Seed додає barsik, murka й tom через `$setOnInsert`: повторний запуск зберігає
користувацькі зміни. Колекція використовує автентифікацію; роль застосунку
має лише `readWrite` для `cats_db`, без доступу до іншої БД чи адміністрування.

| Меню | Функція | Поведінка |
| --- | --- | --- |
| 1 | `read_all_cats` | Усі коти, сортування за ім'ям |
| 2 | `read_cat_by_name` | Один документ або повідомлення про відсутність |
| 3 | `create_cat` | Перевірка полів, повернення ObjectId |
| 4 | `update_cat_age` | Зміна віку наявного кота |
| 5 | `add_cat_feature` | `$addToSet`, без повторів |
| 6 | `delete_cat_by_name` | Видалення за ім'ям |
| 7 | `delete_all_cats` | Потрібне явне введення `DELETE` |
| 0 | — | Завершення роботи |

`update_cat_age` і `add_cat_feature` повертають `UpdateResult` PyMongo:
`matched_count` показує кількість знайдених документів, `modified_count` — змінених
([документація драйвера](https://www.mongodb.com/docs/languages/python/pymongo-driver/current/crud/update/#return-value)).
Меню розрізняє три результати одного запиту без додаткового читання:

- `matched_count == 0`: кота не знайдено;
- `matched_count == 1` і `modified_count == 0`: вік уже має задане значення
  або характеристика вже є; запит виконано, змін не потрібно;
- `modified_count == 1`: вік або характеристику збережено зі зміною документа.

Помилки операцій `PyMongoError` обробляються через `try/except` у меню:
виводиться безпечна діагностика, повідомлення про успіх не з'являється,
і можна виконати наступну команду. CRUD-функції передають винятки викликувачу.
Дублікати імен і некоректне введення не завершують меню.
EOF та Ctrl+C завершують програму без traceback. Дані й меню йдуть у stdout,
помилки — у stderr; помилка запуску повертає код 1, успіх — 0.
Деталі винятків драйвера не друкуються, бо можуть містити облікові дані.
